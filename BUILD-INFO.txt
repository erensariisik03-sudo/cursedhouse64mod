Artifact: source package for libmultiplayermod.so + local Turkish SEDA ASR
Build target: Android arm64-v8a / ELF64 AArch64 / API 21+
Android NDK (GitHub Actions): r27c 27.2.12479018
Sherpa-ONNX: v2.0.3 C API, Android arm64-v8a
SEDA model: atasoglu/seda-v0.2-tiny c32, greedy_search, CPU, 1 thread
Model runtime package: separate gmm_seda/ model archive (CC BY-SA 4.0)

Important artifact distinction:
- This ZIP contains source code and a GitHub Actions workflow.
- It does NOT contain a prebuilt libmultiplayermod.so.
- On push / pull_request / workflow_dispatch, GitHub Actions builds the
  sherpa-onnx C API and ONNX Runtime, builds the mod with MM_ENABLE_SEDA=ON,
  downloads the SEDA c32 model, validates ARM64 ELF LOAD alignment, and
  uploads an artifact named:
  multiplayermod-arm64-v8a-with-seda-v0.2-tiny
- The Actions artifact contains dist/arm64-v8a/{libmultiplayermod.so,
  libsherpa-onnx-c-api.so,libonnxruntime.so} and
  dist/seda-v0.2-tiny-c32.zip.

Implemented changes:
- Removed `gemini-3.5-flash` from the model list; `gemini-3.1-flash-lite-preview`
  remains first. Existing sequential fallback/cooldown remains; the proposed
  parallel two-model race is not part of this package yet.
- Local SEDA v0.2-Tiny speech-to-text via sherpa-onnx C API; audio PCM is
  transcribed on the device and is never attached to Gemini requests.
- The same deterministic message_gate::Evaluate filter is used by typed chat
  and voice transcripts. Existing general-filter and name-addressing toggles
  are passed to both routes.
- Locally generated small-talk replies, noise/laugh rejection, addressing to
  other players, name requirements, profanity warnings and conversation state
  are handled before any Gemini call. Complete local greetings are answered
  without a bot-name mention (preserving the project's established behavior);
  the name gate applies to normal AI requests only.
- Short-utterance segmentation threshold lowered to 0.55 s span / 0.35 s voiced
  content; 0.9 s silence closes a segment; maximum recording 12 s.
- PCM sample-rate conversion uses weighted averaging to reduce aliasing while
  converting to 16 kHz mono.
- Model files are downloaded separately and installed under the app-specific
  external files path with tools/install_seda_android.ps1.

Known limitations / device checks:
- SEDA v0.2-Tiny is Turkish-only. The selected c32 greedy configuration is
  latency-oriented; the model card reports 17.30 WER on FLEURS-TR for this
  fast setting. Other languages, game-specific names, overlapping speech,
  compression and noisy room audio may reduce accuracy further. The reported
  ~7 MB is the acoustic model file size, not total runtime RAM.
- Model inference and actual peak RAM/latency must be measured on the target
  Android device; the source uses one CPU thread and lazy initialization.
- The model archive is separate from the native libraries. Install model files
  under /sdcard/Android/data/<package>/files/gmm_seda, restart the game, and
  keep the three ARM64 shared libraries together in the native loader path.
- No physical Android game, real Photon room, or real Gemini key was used for
  these local fixture tests.
